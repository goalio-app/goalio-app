# Goalio

Pronos foot du jour : fiables, fun, buteurs après les compos, combinés et montante.
Site installable sur iPhone (Safari → Partager → Sur l'écran d'accueil).

Les pronos sont dans `data.json`, mis à jour automatiquement chaque matin et toutes les heures de 11 h à 22 h.
